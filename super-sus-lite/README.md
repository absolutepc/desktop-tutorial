# Station Suspect

Браузерная игра в духе **Super Sus / Among Us**: социальная дедукция на одной карте станции с ботами.

## Играть с телефона

После деплоя GitHub Pages открой:

**https://absolutepc.github.io/desktop-tutorial/**

Пока Pages не включён: Settings → Pages → Source → GitHub Actions (или Deploy from branch → `/docs`).

### Управление на телефоне

- Джойстик слева — движение
- **Действие** — задача / донос / SOS (удерживать на задаче)
- **Убить** — только для импостера

## Как играть на компьютере

Открой `super-sus-lite/index.html` в браузере или ту же ссылку Pages.

### Клавиатура

| Клавиша | Действие |
|--------|----------|
| WASD / стрелки | Движение |
| E | Задача / донос о теле / кнопка SOS |
| Q | Убийство (если ты импостер) |
| Space | Экстренное собрание у красной кнопки |

### Цель

- **Член экипажа** — выполни все задачи или изгони импостера на голосовании.
- **Импостер** — устраняй экипаж, пока импостеров не станет не меньше, чем живых членов экипажа.

## Что внутри

- Карта станции с комнатами
- Случайная роль (экипаж / импостер)
- 5 ботов с простым ИИ
- Задачи, трупы, доносы, экстренные собрания и голосование
- Сенсорное управление для телефона

Это локальный прототип без онлайн-мультиплеера.
